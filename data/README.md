# Data

The source CSV is intentionally not committed to this repository.

From the project root, download the five-class dataset with:

```bash
curl -L "https://raw.githubusercontent.com/QiuyiWu/Epileptic-Seizure-Recognition-Data/master/A%26B%26C%26D%26E.csv" \
  -o data/epileptic_seizure_data.csv
```

The analysis expects the resulting file at `data/epileptic_seizure_data.csv`.
